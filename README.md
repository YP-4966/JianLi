## 技术方案

- **纯静态 HTML**：单文件架构，所有 CSS 样式和图片均内联，无外部依赖
- **A4 纸张模拟**：210mm x 297mm 页面尺寸，还原 Word/WPS 打印效果
- **响应式设计**：适配桌面、平板和手机三种屏幕
- **打印友好**：`@media print` 样式优化，可直接打印为 PDF
- **GitHub Pages 部署**：使用 `.nojekyll` 跳过 Jekyll 构建，直接托管静态文件

## 管理操作

### 修改简历内容
直接编辑 `index.html` 文件，提交后 GitHub Pages 会自动更新。

### 设置仓库可见性
- **私有**：Settings → Danger Zone → Change visibility → Make private
- **公开**：Settings → Danger Zone → Change visibility → Make public

### 删除文件
```bash
git rm <文件名>
git commit -m "删除文件说明"
git push origin main
```
